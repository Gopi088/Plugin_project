Automated score aggregation and pushed results into Grafana dashboards, with visualizations bucketed as per response
quality.

Outcomes:

ML Projects (Pre-LLM Work) - Service Request(SR) CLASSIFICATION
Developed a machine learning model to classify Service Requests (SRs) into Consultative (questions) or Problem (issues/errors) categories. The model leveraged SR metadata and textual descriptions to improve triage accuracy and reduce turnaround time for consultative SRs, which were historically overshadowed by problem SRs.
Key Responsibilities:
Engineered features from SR fields including summary, problem description, category/sub-category, component, severity.
Built and tested multiple ML algorithms, ultimately selecting XGBoost based on superior F1 performance on a held-out validation dataset.
Designed a text processing pipeline using unigrams, bigrams, and trigrams with TF-IDF weighting; applied class-specific boosting to handle class imbalance.
Conducted multiple iterations of model tuning to maximize class discrimination, achieving strong generalization across multiple product lines.
Outcomes:
Achieved significant improvements in SR triage efficiency, enabling faster handling of consultative queries (previously buried within ~85% problem SR volume).
Reduced manual redirection effort, saving support engineers substantial time in SR classification.
Demonstrated cross-product applicability, with a model trained on one product set generalizing well to others.
This model was integrated with the Oracle Support portal to automatically label SRs at creation time.
