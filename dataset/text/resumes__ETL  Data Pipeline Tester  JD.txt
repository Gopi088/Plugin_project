ETL / Data Pipeline Tester – Databricks &
Azure
5–8 Years | Bangalore (Preferred) | Immediate Joiners
About the Role
We are looking for an ETL / Data Pipeline Tester to support a large-scale data platform
built on Databricks, Azure Data Factory, and Azure services.
This is a hands-on contract role focused on data validation, data quality, and
pipeline testing rather than UI or manual application testing.
The ideal candidate has real experience validating data flows, understanding
transformations, and identifying data discrepancies across large datasets.
Key Responsibilities
• Validate ETL data flows across source, transformation, and target layers
• Perform data reconciliation and quality checks (row counts, aggregates,
mismatches)
• Test Databricks-based transformations using SQL and notebooks
• Validate Azure Data Factory (ADF) pipelines, activities, dependencies, and
reruns
• Conduct data validation for large datasets and support performance
benchmarking
• Test Azure Functions–based workflows for correctness and reliability
• Support load and performance testing using tools like JMeter or BlazeMeter
(exposure is sufficient)
• Validate data consistency between backend datasets and Power BI reports
(optional / plus)
• Perform root cause analysis for data discrepancies and pipeline failures
Must-Have Skills
• Strong experience in ETL / data pipeline testing
• Hands-on data validation and reconciliation experience
• Working knowledge of Databricks (tables, SQL, transformations)
• Experience testing Azure Data Factory (ADF) pipelines
• Good SQL skills for validation and troubleshooting
• Ability to reason about data quality and transformation issues
Good-to-Have / Plus Skills
• Exposure to JMeter / BlazeMeter for performance or load testing
• Experience validating Power BI datasets or reports
• Testing Azure Functions or automated workflows
• Basic test automation or scripting experience (Selenium or open-source tools)
• Familiarity with using AI tools for test case generation or debugging
Experience & Other Details
• Experience: 5–8 years
• Location: Bangalore preferred (flexible for strong profiles)
• Notice Period: Immediate or short notice strongly preferred
What We’re Looking For
• Practical, execution-focused testers
• Candidates who can explain how they validate data, not just list tools
• Above-average quality suitable for a fast-moving contract engagement
(This is not a UI automation or manual QA role.)
