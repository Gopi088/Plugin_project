Product Name: ENCollect (Sumeru Product)

Framework: .Net Framework 4.0
Operating System: Windows 10
Environment: MVC4.0, LINQ, C#, WEB APIs, SQL Server 2014, SSIS
Role: Senior Software Developer
Tools: TFS
This is a Collection software and can be used by any organization who wish to automate the collection process, it can be money collection, document collection, Food Product etc.
How it works
ENCollect can be used while on Move (mobile app version) as well as through browser. Mobile ENCollect has features to use while being offline as well.
Customer from whom money needs to be collected will populate in Agent login based on business logic defined by the organization.
Agent can see responsible cases and customer details such as address and amount to be collected.
Payments are recorded in the mobile app; SMS and email notifications are sent, and hard-copy receipts can be generated through a Bluetooth printer.
Receipt functionality can be used in offline mode.
Agent is authorized to issue a Cancel Receipt and take back the money when applicable.
Details are displayed on the fly in dashboards for Agent, supervisors and Backend Admin.
Agency Manager collates payments and creates batches; Bank representatives process batch-wise payments and issue collection receipts.
Payment categories include Cheque, DD and Cash, followed by Payinslip generation and collection confirmation.
At end of day, status is updated in Core Banking System and updated payment status and new cases reflect in ENCollect next day.
