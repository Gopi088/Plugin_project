Project             : MBL (Micro Business Loan)
Team Size        : 13
Client               : IDFC First Bank

Description:
Micro Business Loan (MBL) is a web-enabled product that allows you to manage loan transactions for micro business (e.g. Loan initiation for small business, DDE etc).
Features:
There are so many stages in MBL such as 
CPA FTS, DDE, UNDERWRITER, OFFERING, OPS DATA CHECK.

First user needs to enter some basic details of customer, while he is submitting loan application form. After submitting application, a loan number will generate.
After that it will call a web service called FICO, where it will check if the customer is already applied for loan or first time, he is applying in IDFC.

After the success response from FICO, it will come to the local branch manager's id and stage became CPA FTS stage where all the data what is filed by user is only readable. Means branch manager can’t edit this.

If the branch manager submits the application, then it will move to second stage which is DDE (Detail data entry). If incase branch manager rejected the application due to some internal policy then it will go back to SALES FTS STAGE where sales person (User) only can view this application, while rejecting and approving the application all manager including branch manager have to right the reason for reject/approve.

In DDE stage, again some extra details need to be filled by user like full details of applicant and his guarantor or co-applicant, address of applicant and co-applicant like this.

If the concern manager submits the application, it will go to UNDERWRITER stage, if he rejected then it will be rejected. The applicant’s loan got rejected.

in underwriter stage the applicants (Who applied for loan) application will be viewed by some higher-level manager. If everything goes well then, the application will move to OFFERING stage. After the submit of application in offering stage, it will move to OPS data check Stage and finally it will submit to FINNONE team for disbursement of loan.
