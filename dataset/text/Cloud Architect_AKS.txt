Cloud DevOps Engineer – Azure AKS Focus
Job Description

At Publicis Groupe, we are accelerating our cloud transformation journey by leveraging Microsoft Azure to modernize infrastructure, enhance scalability, and drive innovation. We are seeking a skilled Cloud Architect or Engineer with deep expertise in Azure Kubernetes Service (AKS), Azure Networking, containerization, and core Azure infrastructure components. This role will collaborate closely with our DevOps, Infrastructure and development teams to design, implement, and support robust cloud-native solutions.

Key Responsibilities
Design, deploy, and manage scalable solutions using Azure AKS, App Service, and container technologies.
Architect and maintain Azure networking components including VNets, NSGs, Load Balancers, Application Gateway, Private Endpoints, and Private DNS Zones.
Manage Azure identities and access, including role-based access control (RBAC) and Azure Active Directory (AAD) integrations.
Support and optimize Azure Virtual Machines and PaaS databases (e.g., Azure SQL, Cosmos DB) as part of hybrid cloud solutions.
Support and maintain Azure storage solutions, including Blob Storage, File Shares, and managed disks.
Implement and maintain Infrastructure as Code (IaC) using Terraform.
Familiarity with cloud security best practices and compliance frameworks, including ISO 27001, SOC 2, GDPR, and HIPAA. This role will require strong fundamental cloud security best practices as well as recommending solutions to clients on how to remediate vulnerabilities as well as design flaws.
Collaborate with DevOps teams to build and optimize CI/CD pipelines using GitHub Actions and other Azure-native tools.
Experience designing technical cloud environments after translating them from business requirements.
Ensure secure and efficient integration of Azure services across environments.
Monitor, troubleshoot, and optimize cloud infrastructure performance and reliability using tools like Azure Monitor and Log Analytics.
Participate in incident response and root cause analysis for cloud-related issues.
Advocate for automation and continuous improvement across infrastructure and deployment processes.

Required Skills and Qualifications
Bachelor’s degree in Computer Science, Information Technology, or related field.
Fluent in English.
3+ years of hands-on experience with Azure cloud services, especially AKS, networking, and virtual machines.
5+ years experience in designing cloud enviromnments
Strong understanding of container orchestration, Docker, and Kubernetes.
Experience with IaC tools, specially Terraform.
Solid experience with GitHub, GitHub Actions, and CI/CD pipeline design.
Solid scripting skills (e.g., PowerShell, Bash, Python).
Excellent troubleshooting and problem-solving abilities.

Preferred Qualifications
Experience working in a DevOps culture, collaborating with development teams.
Knowledge of Azure DevOps, monitoring tools (e.g., Azure Monitor, Log Analytics).
Experience with Linux-based infrastructure.
Understanding of cloud governance and security best practices.
Azure Certifications (e.g., AZ-104, AZ-400, AZ-305).
